# LAWS — cross-project knowledge base

Findings that would hold on a different project, with different assets.
Promoted at end of session per PROTOCOL.md rule 6 — never "later".

Format, one law per entry:

```
## <YYYY-MM-DD-short-kebab-slug>
<One crisp sentence stating the law.>
Evidence: <pointer to where the measurement/observation lives>
Confidence: measured | single observation | reasoned, not measured
Status: live | superseded by <law id> — <what killed it>
```

Rules of the file:

- Every law gets an **id** (`YYYY-MM-DD-slug`), never a sequential number.
  Two sessions can mint ids without coordinating; identical ids mean the
  same law was found twice, which is a merge, not a collision.
- A superseded law is **marked, not deleted**. A retired law is as useful
  as a live one — it stops the next session from re-deriving the mistake.
- Reference laws by id in project notes and commit messages.
